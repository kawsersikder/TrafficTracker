# Dataset Collection — Cross-City Traffic Congestion Study

All datasets used in the CSE498R project *"Cross-City Deep Learning for Traffic Congestion in South & Southeast Asian Megacities"* (see [../RESEARCH_PROPOSAL.md](../RESEARCH_PROPOSAL.md)).

Each subfolder contains a `README.md` with **full credits** (source repository, research paper, license), the **dataset type**, and **how we use it** in the pipeline. Raw data lives in each folder's `raw/` subdirectory and is **git-ignored** (too large for the repo) — every README documents exactly how to re-fetch it, including one-liners that work on **Google Colab / Kaggle notebooks**.

## How Everything Links Together

```
                        ┌────────────────────────────────────────────────┐
                        │   STEP 1 — UNIFIED CONGESTION INDEX (UCI)      │
                        │   normalize every source to CI ∈ [0,1]         │
                        │   per road segment per time bin                │
                        └────────────────────────────────────────────────┘
   Bangkok (MeTS-10)      CI = 1 − speed / free-flow speed
   Dhaka (TrafficTracker) CI = ordinal map of Google Maps color scoring
   Jakarta (Zenodo/HERE)  CI = jam_factor / 10
   Manila (benjiao logs)  CI = ordinal map of {L, ML, MH, H} status
                        ┌────────────────────────────────────────────────┐
                        │   STEP 2 — CHARACTERIZATION (classical stats)  │
                        │   peak profiles · weekly cycles · onset/       │
                        │   recovery · spatial concentration             │
                        └────────────────────────────────────────────────┘
                        ┌────────────────────────────────────────────────┐
                        │   STEP 3 — FORECASTING (ML → DL ladder)        │
                        │   ARIMA / XGBoost  →  LSTM / GRU / TCN  →      │
                        │   ST-GNN (Graph WaveNet, DCRNN)                │
                        └────────────────────────────────────────────────┘
                        ┌────────────────────────────────────────────────┐
                        │   STEP 4 — TRANSFER (headline experiment)      │
                        │   pre-train Bangkok → zero-shot / fine-tune    │
                        │   on Dhaka, Jakarta, Manila (k-day curves)     │
                        └────────────────────────────────────────────────┘
   Side track (vision): TFP-BD + DhakaAI + Poribohon-BD → YOLOv8 vehicle
   detection → heterogeneity features (% rickshaw/CNG/bus) → explain WHY
   transfer succeeds or fails per city.
```

## Model Plan (summary)

| Stage | Model | Library | Runs on |
|---|---|---|---|
| Baselines | Historical average, ARIMA, XGBoost | statsmodels, xgboost | anywhere |
| Deep sequence | LSTM, GRU, TCN | PyTorch | Colab (T4/A100) |
| Spatio-temporal | Graph WaveNet / DCRNN on road graph | PyTorch Geometric | Colab Pro |
| Transfer | Pre-train + fine-tune, k ∈ {1,3,7,14,28} days | PyTorch | Colab Pro |
| Vision side track | YOLOv8 (fine-tuned) | ultralytics | Colab / Kaggle GPU |
